## 已修复

- 50001、50008、50014明确报告 `login_required`，附业务码；其他业务拒绝不再一律要求重新登录。
- 导入会话时先GET官方账号接口验证登录和等待时间字段。验证失败时保留原文件。
- 验证通过后原子替换本地会话，记录验证时间；不输出Token、不发送领取POST。
- 领取任务运行时禁止替换会话，避免等待期间更换账号状态。
- 根证书检测同时枚举CurrentUser和LocalMachine根存储，不依赖PowerShell的Cert路径。
- 提供只读Diagnose-Certificate.ps1，用于比较桌面环境和脚本进程的证书视图。

## 仍缺少的输入

需要一份账号本人有效、合法取得的平台请求文件，含当前会话。微信和小程序重新登录不会自动更新脚本的private/session.json。不要在聊天或GitHub发送Token，不扫描其他软件的凭据存储。

若本人已获得新的平台请求文件，可使用客户端既有的import-session入口导入。它现在会先验证再替换。后续还需doctor和60元券试运行通过，再按实时官方轮次启动任务。此处的导入入口不会采集流量或安装证书。
